How the HTML video attributes work

autoplay asks the browser to start when ready. muted helps autoplay work within browser policies. loop restarts the video at its end. controls adds native player controls; this canvas wall has its own Play and Pause buttons.

The wall draws one original local MP4 into 500 visual tiles for performance. It does not open YouTube, create 500 separate players, or affect any video’s view count. Picked files stay in this browser and are not uploaded.
