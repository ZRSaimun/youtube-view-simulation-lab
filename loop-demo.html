CLASS DEMO · HTML MEDIA LOOP CONCEPT

What does “loop forever” do?

This local animation repeats until you pause it. It demonstrates looping behavior without sending playback to YouTube or changing any video’s view count.

For a local HTML5 video

<video controls loop>
  <source src="sample.mp4" type="video/mp4">
</video>

YouTube note: the IFrame Player API uses loop=1 together with playlist=VIDEO_ID for a single-video loop. This class demo intentionally doesn’t autoplay or repeatedly play a real YouTube video, because repeated playback can create artificial engagement.
