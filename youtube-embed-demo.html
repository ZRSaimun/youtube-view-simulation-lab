CLASS DEMO · YOUTUBE EMBED URL

Paste a YouTube link

Paste a YouTube link and click Load video. When the player appears, click YouTube’s red Play button inside it to start. Loading the player does not start playback.

Accepts youtube.com/watch, youtu.be, /embed/, /shorts/, and 11-character video IDs. After loading, press Play inside the YouTube player.

Press “Load video” to show the sample player.

Embed code

Playback: the embed is click-to-play. It does not autoplay or loop. This demo converts a YouTube link to an embed URL; YouTube links cannot be used as the source of an HTML <video> element.
